# License scope - revised candidate 1.1.0

This preserves the author decisions recorded 24 October 2026 while specifying the new corpus and production materials. It does not change licenses on existing v1.0.0 files.

| Material | Scope / terms |
|---|---|
| Author-owned manuscript prose, original figure presentation and editorial source | CC BY 4.0; upstream coordinate/data attribution remains attached to figure source data |
| Eligible independently authored original analysis/production code | MIT author license, conditional on actual ownership; third-party text is not relicensed |
| BioEmu original XTC/topology and associated coordinate lineage, including supplied stage PDB corpus | Source attribution and CDLA-Permissive-2.0 accompaniment; no author claim to upstream ownership |
| Computed CSV, NPZ, intervention coordinates, receipts and archived diagnostic records | Preserve data provenance and applicable upstream terms; CDLA agreement accompanies these data; no blanket author MIT/CC BY assignment |
| Microsoft BioEmu / benchmark source or reused substantial source portions | Upstream Microsoft MIT; preserve notice and license |
| H-Packer/BioEmu model weights and full upstream installations | Not redistributed; hashes and citations only |
| Third-party prior publications | Referenced, not republished in this release candidate |

`provenance/Rights_Manifest.csv` maps individual files to these categories. `MIT_MICROSOFT_BIOEMU_BENCHMARK_CODE.txt` is retained for Microsoft code; CDLA full agreement is retained alongside data. The record-level license field in Zenodo cannot replace these per-file distinctions. No public metadata has been changed in P1.

A human prepublication check of author-owned/reused code and accurate record-level metadata remains required; this is a scoped production declaration, not an independent legal opinion.
