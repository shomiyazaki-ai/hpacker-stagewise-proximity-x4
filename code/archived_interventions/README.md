# Archived X4 local-intervention implementations

The four scripts are archival research implementations, **not a newly validated standalone reproducibility package**. Their original dependent upstream HPacker/BioEmu environment, local inputs and model-weight versions must be reconstructed separately. No full end-to-end rerun or Phase 2B independent audit is claimed.

The reported v8.1 masking removes specified side-chain atoms from local neighborhood arrays; the lag branch temporarily substitutes stage s−2 side-chain coordinates. The high/low response cases are selected **post hoc**. See SI S4 and original study evidence. No new scientific execution was performed in assembling this archive.
